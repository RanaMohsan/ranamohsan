# Original WPF Repositories

These files were uploaded from the original PayNex desktop POS. They are kept here as source reference for the cloud conversion.
They are not compiled directly because they depend on WPF/session-specific classes such as `PosSession`, `Db`, and desktop print services.
The cloud API already exposes converted endpoints for products, customers, vendors, POS sales, purchases, shifts, returns, finance, and reports.
