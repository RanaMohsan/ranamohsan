Simple Process

  1. Export Excel
  2. Add or edit rows
  3. Import Excel
  4. Validate
  5. Save

Export Behaviour

Export always downloads an Excel file. When no ERP record exists, the file still contains the correct column headings so new rows can be added.

Validation Rule

Save remains disabled until the imported file passes validation. Saving runs in one SQL transaction and rolls back completely if an error occurs.
