OTP & User Login Mailbox

Login OTP codes and new-user login details (email and initial password) are sent from this mailbox. The SMTP password is encrypted before it is stored in the master database.

Test Configuration

Security Behavior

A new user first receives login details from this mailbox. On first login, a new browser/device, or after the configured trust period expires, the same mailbox sends a one-time OTP. Successful OTP verification trusts that browser for 30 days by default.
Production: Disable “Return OTP in API response.” Use an app password, SMTP relay credential, Microsoft Graph, or another controlled sender mailbox.

Only the InterNex Platform Owner can open this page or call its APIs. Company administrators and normal users cannot view the SMTP configuration.
