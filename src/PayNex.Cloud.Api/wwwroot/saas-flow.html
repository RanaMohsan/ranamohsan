Multi-Client Cloud SaaS Flow

One cloud application and one domain, with a separate isolated database for every registered client/company.

PayNex PortalClient LoginWorkspace

Client Onboarding Automation

01
Register CompanySuper Admin enters company, owner, license and user details.
02
Generate Company CodeSystem creates a unique login code such as PNX000001.
03
Create Client DBSystem creates a separate tenant database such as PayNex_ABCSTORE_DB.
04
Apply Default SetupTables, roles, users, COA, posting setup, tax and payment methods are seeded.
05
Activate ClientLicense, subscription, database status and workspace become active.
06
Client LoginClient uses the same application URL but sees only their own company data.

Master Database

  • Client/company list
  • Company code and database name
  • Subscription and license
  • Trial, renewal and expiry
  • Admin contact and provisioning status

Client Database

  • Users and roles
  • Products, customers and vendors
  • Sales, purchases and inventory
  • Customer/vendor ledgers
  • G/L entries, dashboard, reports and settings

Login Rule

Every client uses the same app URL. The Company Code selects the correct client database before the workspace opens.
