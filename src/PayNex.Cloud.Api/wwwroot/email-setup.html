Security Behavior

First login: OTP is always required for every user.
Every login: turn on “OTP on every login” on that company’s Company Card.
This page: Enable OTP emails + save Gmail App Password so codes can be delivered.
Production: Disable “Return OTP in API response.” Use an app password, SMTP relay credential, Microsoft Graph, or another controlled sender mailbox.
