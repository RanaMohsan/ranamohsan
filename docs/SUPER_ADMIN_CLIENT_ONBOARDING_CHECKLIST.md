# Super Admin Client Onboarding Checklist

## Before Creating Client

```text
Company legal/business name
Owner/admin name
Owner/admin email
Owner/admin mobile
Subscription plan
Allowed branches
Allowed users
Allowed counters
```

## After Clicking Register Company

System should automatically show:

```text
Generated Company Code
Created Client Database Name
Client Admin Username
Client Status
License Status
Provisioning Status
Login URL
```

## Details to Give Client

```text
URL: app.paynex.com
Company Code: Generated code
Username: admin
Password: configured password
```

## Super Admin Controls

```text
Activate client
Deactivate client
Suspend license
Renew subscription
View database status
View provisioning status
Copy login details
```
