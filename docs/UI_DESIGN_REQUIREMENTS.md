# PayNex Cloud UI Design Requirements

The application uses a modern ERP/POS workspace visual design.

## Main theme
- Fixed dark navy sidebar.
- White header bar and white content cards.
- Soft light-blue background.
- Cyan accent buttons.
- Green save/post/pay actions.
- Pink-red destructive/reversal actions.
- Amber warning notes.
- Rounded corners, soft shadows and clean grid styling.

## Color palette
- Primary dark navy: `#07122F`
- Secondary dark blue: `#102052`
- Main background soft blue: `#F4F8FF`
- Card/panel background: `#FFFFFF`
- Accent cyan: `#00C8F8`
- Secondary accent amber: `#FFB703`
- Success green: `#11CDA4`
- Danger pink-red: `#EF3E6D`
- Main text dark: `#111827`
- Muted text gray-blue: `#64748B`
- Alternate grid row: `#EAF6FF`
- Selected grid row: `#BDEFFF`
- Light border: `#E2E8F0`
- Light blue border: `#B9DDF3`

## Implemented screen design
- Login two-column layout with dark branding panel and white login card.
- Sidebar shell with user, role, shift status, menu and logout.
- Header bar with page title, toggle and date/time.
- Home workspace action tiles with icon circles, group and hints.
- POS billing cashier layout with cart and dark total panel.
- Picture sales touch-friendly product tiles.
- Dashboard analytics cards and chart cards.
- Master data split layouts.
- Finance and ledger grids with dark navy headers.
- Settings warning and backup/restore action styling.
- Print-friendly report styling.
